Engineered for Reliability in Mind

How NexusCUH solves the fatal flaws of naive screenshot-clicking wrappers through hierarchical orchestration.

Tri-Modal Cognitive Router

Standard computer-use agents rely exclusively on screenshots and mouse clicks ($1,600$ visual tokens per step, hallucinated pixel coordinates, high latency). NexusCUH implements a 4-tier cognitive priority hierarchy:

  • Priority 1: MCP Software Tools — Executes deterministic API actions on desktop software (StoryTold WordCraft, SheetCraft, SQL) with 0 visual tokens and 100% precision.
  • Priority 2: Direct FileSystem Tools — Atomic read, write, append, and search avoiding shell escaping bugs.
  • Priority 3: Stateful Shell Session — Background PTY execution with windowed head/tail output truncation.
  • Priority 4: Desktop GUI Fallback — Perceptual frame diffing deduplicates unchanged screens to preserve context.
router.py 
# Cognitive Routing Hierarchy
PRIORITY = {
    "mcp": 1,         # 100% Deterministic, 0 Visual Tokens
    "filesystem": 2,  # Atomic I/O, Safe Quoting
    "shell": 3,       # Batch processing, CLI tools
    "computer": 4     # GUI clicks & visual verification
}

Model Context Protocol (MCP) Bridge

Direct native integration with StoryTold desktop applications (WordCraft, DeckCraft, ArtCraft) and arbitrary enterprise software.

  • JSON-RPC 2.0 Stdio/SSE Engine — Asynchronous process management with multiplexed requests.
  • Dynamic Tool Translation — Automatically maps MCP tool schemas into Anthropic, OpenAI, and Gemini function signatures.
  • AST & Layout Parity — Directly query document tree structures and assert rendering parity.

Ground-Truth Multi-Modal Verification

Exit code zero does NOT mean a task succeeded. NexusCUH evaluates assertions against actual disk and application state.

  • File Hash & JSON Assertions — Verifies SHA-256 signatures, row counts, and JSON schemas.
  • MCP State Assertions — Queries application internal AST rather than relying on visual guesses.
  • Cryptographic Evidence Logs — Produces diagnostic proof of execution for audits.
verifier.py 
verifier = MultiModalVerifier([
    FileExistsAssertion("reports/summary.json"),
    FileJsonAssertion("reports/summary.json", {"total": 412.50}),
    MCPStateAssertion("wordcraft", "inspect_document", {}, check_paragraphs)
])
report = await verifier.verify(sandbox, mcp_manager)

Developer Quickstart

Install, launch the sandbox, and run your first computer use task in under 60 seconds.

1

Install with uv

Clone the repository and install dependencies in an isolated virtual environment:

bash 
git clone https://github.com/subasah/computer-use-harness.git
cd computer-use-harness
uv venv && source .venv/bin/activate
uv pip install -e ".[dev]"
2

Configure Environment

Copy the environment template and configure your provider API key:

bash 
cp .env.example .env
# Set ANTHROPIC_API_KEY=your_key or use offline mock
3

Run Task or Benchmark

Execute any task or run the full evaluation suite with rich telemetry:

bash 
# Run evaluation suite
nexus eval --output results.md

# Inspect connected MCP tools
nexus mcp

# Run custom task
nexus run -t "Create memo in WordCraft" -p mock
